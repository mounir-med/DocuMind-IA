                         QUE FAIT CETTE APPLICATION ?
═══════════════════════════════════════════════════════════════════════════

DocuMind AI vous permet de :

📄 UPLOADER des PDF
   → Extraction automatique du texte
   → Indexation vectorielle intelligente

💬 POSER DES QUESTIONS
   → Chat IA avec recherche sémantique (RAG)
   → Sources traçables avec numéros de page

📝 GÉNÉRER DES RÉSUMÉS
   → Court, détaillé, ou par chapitre

🎓 CRÉER DES QCM
   → Génération automatique de quiz
   → 3 niveaux de difficulté

🔄 COMPARER DES DOCUMENTS
   → Analyse comparative multi-PDF

═══════════════════════════════════════════════════════════════════════════
                            STACK TECHNIQUE
═══════════════════════════════════════════════════════════════════════════

Backend :
  • FastAPI (Python)
  • ChromaDB (vector store)
  • sentence-transformers (embeddings multilingues)
  • SQLite (base de données)
  • PyMuPDF (extraction PDF)

Frontend :
  • Next.js 15 (React)
  • TypeScript
  • Tailwind CSS
  • Design moderne et responsive
